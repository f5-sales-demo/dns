Este guia apresenta um **exercício completo de DNS** no F5 Distributed Cloud, orientado por Terraform.
Está estruturado em quatro fases que um operador humano ou um assistente de IA pode executar de ponta a ponta. Cada
fase é idempotente: executá-la novamente converge para o mesmo estado.

## Fases do exercício

| Fase | Objetivo |
| --- | --- |
| [Fase 1 — Construção](/dns/demo/phase-1-build/) | Implantar a zona DNS primária com Terraform; configurar estado remoto e CI |
| [Fase 2 — Validação](/dns/demo/phase-2-validate/) | Confirmar que a zona resolve na internet pública e que o plano é idempotente |
| [Fase 3 — Failover](/dns/demo/phase-3-failover/) | Adicionar um balanceador de carga DNS com failover verificado por integridade *(pendente o módulo DNS-LB)* |
| [Fase 4 — Desmontagem](/dns/demo/phase-4-teardown/) | Destruir os objetos gerenciados após confirmação explícita |

## Pré-requisitos

- **Terraform** ≥ 1.5.
- O provedor **`f5-sales-demo/xcsh`** ≥ 3.61.15 (a primeira versão que inclui os recursos de DNS),
  resolvido pelo registro do Terraform — ou uma compilação local via `dev_overrides`.
- Um **token de API do F5 XC** com acesso ao namespace `system`.
- A **CLI do Azure**, autenticada com permissão de Contribuidor na assinatura, para o bootstrap
  único do backend de estado.

<Aside type="caution">
O domínio utilizado aqui está delegado ao F5 XC, portanto os registros criados resolvem na internet pública.
Utilize um domínio de sua propriedade que você pretenda gerenciar — o plano é orientado por variáveis precisamente para que você possa direcionar ao seu próprio domínio.
</Aside>

Comece pela [Fase 1 — Construção](/dns/demo/phase-1-build/).
