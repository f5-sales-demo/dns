Este guia apresenta um **exercício completo de DNS** no F5 Distributed Cloud, orientado pelo Terraform.
Ele é estruturado em quatro fases que um operador humano ou um assistente de IA pode executar de ponta a ponta. Cada
fase é idempotente: executá-la novamente converge para o mesmo estado.

## Fases do exercício

| Fase | Objetivo |
| --- | --- |
| [Fase 1 — Construir](/dns/pt-br/demo/phase-1-build/) | Implantar a zona DNS primária com Terraform; configurar estado remoto e CI |
| [Fase 2 — Validar](/dns/pt-br/demo/phase-2-validate/) | Confirmar que a zona resolve na internet pública e que o plano é idempotente |
| [Fase 3 — Failover](/dns/pt-br/demo/phase-3-failover/) | Adicionar um balanceador de carga DNS com failover baseado em verificação de integridade *(pendente o módulo DNS-LB)* |
| [Fase 4 — Encerrar](/dns/pt-br/demo/phase-4-teardown/) | Destruir os objetos gerenciados após confirmação explícita |

## Pré-requisitos

- **Terraform** ≥ 1.5.
- O provedor **`f5-sales-demo/xcsh`** ≥ 3.62.0 (namespaces somente de sistema definidos automaticamente por padrão),
  resolvido a partir do registro do Terraform — ou uma compilação local via `dev_overrides`.
- Um **token de API do F5 XC** com acesso ao namespace `system`.
- O **Azure CLI**, autenticado com a função Contributor na assinatura, para o bootstrap inicial do
  backend de estado.

<Aside type="caution">
O domínio utilizado aqui está delegado ao F5 XC, portanto os registros que você criar serão resolvidos na internet pública.
Utilize um domínio que você possui e pretende gerenciar — o plano é orientado por variáveis justamente para que você possa direcionar
para o seu próprio domínio.
</Aside>

Comece com a [Fase 1 — Construir](/dns/pt-br/demo/phase-1-build/).
