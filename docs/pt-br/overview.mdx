Este caso de uso gerencia **DNS autoritativo no F5 Distributed Cloud** com Terraform. Um plano
pequeno e reutilizável cria uma zona DNS primária e seus registros para um domínio delegado, mantém
seu estado no **Azure Blob Storage** e executa plan-on-pull-request / apply-on-merge através do
**GitHub Actions**.

## O que é gerenciado

- Um `xcsh_dns_zone` — uma zona **primária** autoritativa no namespace `system` do F5 XC, com
  registros A. O nome da zona é o domínio delegado (uma variável), portanto redirecionar o alvo é
  uma mudança de configuração, não uma mudança de código.
- Estado remoto do Terraform no Azure, para que as execuções possam ser compartilhadas entre a
  máquina de um operador e o CI.

## Arquitetura

| Camada | Escolha | Por quê |
| --- | --- | --- |
| Provedor | `f5-sales-demo/xcsh` (registro Terraform) | Gerado a partir da OpenAPI do F5 XC; gerencia `xcsh_dns_zone` e os recursos de load balancer de DNS. Autentica com um token de API (`Authorization: APIToken <token>`). |
| Backend de estado | `azurerm` (Azure Blob Storage), autenticação por access-key | Estado durável e compartilhado. A autenticação por access-key é utilizada porque a assinatura concede apenas a função Contributor, que não pode atribuir a função *Storage Blob Data Contributor* necessária para autenticação sem chave (OIDC / Azure AD). |
| Automação | GitHub Actions | Plan em todo pull request, apply ao fazer merge na `main`. As coordenadas do backend e os inputs vêm das **variáveis** do repositório; as credenciais vêm dos **secrets**. |

<Aside type="note">
Todos os objetos de DNS do F5 XC devem residir no namespace `system` — a API rejeita outros
namespaces. O plano impõe isso com uma regra de validação de variável.
</Aside>

## Por onde começar

O arco de [Demonstração](/dns/demo/) percorre o ciclo de vida completo de ponta a ponta: **Build**
da zona com Terraform, **Validação** de que ela resolve, **Failover** com um load balancer de DNS e
**Teardown**. Comece pela [Fase 1 — Build](/dns/demo/phase-1-build/), que é um guia completo para
implantar a zona, incluindo todos os arquivos Terraform, o workflow de CI e as variáveis e secrets
necessários.
