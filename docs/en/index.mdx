**F5 Distributed Cloud DNS** delivers high-performance, resilient, and globally distributed authoritative Domain Name System (DNS) services with built-in DNS load balancing and automated health-based failover.

## Resolution & Routing Architecture

```text
+-------------------------------------------------------------------------+
|                    Global Anycast DNS Resolution Flow                   |
|                                                                         |
|  DNS Client Query (e.g. app.example.com)                                |
|        |                                                                |
|        v                                                                |
|  +-------------------------------------------------------------------+  |
|  | Globally Distributed Anycast DNS Edge PoPs                         |  |
|  +---------------------------------+---------------------------------+  |
|                                    |                                    |
|                                    v                                    |
|  +-------------------------------------------------------------------+  |
|  | Health Check Engine: Continuous Origin Availability Monitoring     |  |
|  +---------------------------------+---------------------------------+  |
|                                    |                                    |
|         +--------------------------+--------------------------+         |
|         | Primary Healthy                                     | Failed  |
|         v                                                     v         |
|  +-----------------------------+               +---------------------+  |
|  | Return Primary VIP A Record |               | Return Failover VIP |  |
|  | (192.0.2.10)                |               | (198.51.100.20)     |  |
|  +-----------------------------+               +---------------------+  |
+-------------------------------------------------------------------------+
```
