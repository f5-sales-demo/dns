本指南將帶您完成在 F5 Distributed Cloud 上由 Terraform 驅動的**完整 DNS 練習**。
整個練習分為四個階段，可由人工操作員或 AI 助理端對端執行。每個
階段均具備冪等性：重新執行將收斂至相同的狀態。

## 練習階段

| 階段 | 目標 |
| --- | --- |
| [第一階段 — 建置](/dns/zh-tw/demo/phase-1-build/) | 使用 Terraform 部署主要 DNS 區域；連接遠端狀態與 CI |
| [第二階段 — 驗證](/dns/zh-tw/demo/phase-2-validate/) | 確認區域可在公共網際網路上解析，且計劃具備冪等性 |
| [第三階段 — 容錯移轉](/dns/zh-tw/demo/phase-3-failover/) | 新增具備健康檢查容錯移轉功能的 DNS 負載平衡器 *(等待 DNS-LB 模組)* |
| [第四階段 — 拆除](/dns/zh-tw/demo/phase-4-teardown/) | 在明確確認後銷毀受管理的物件 |

## 先決條件

- **Terraform** ≥ 1.5。
- **`f5-sales-demo/xcsh`** 提供者 ≥ 3.62.0（系統專用命名空間預設自動套用），
  從 Terraform 登錄檔解析 — 或透過 `dev_overrides` 使用本機建置版本。
- 具備 `system` 命名空間存取權限的 **F5 XC API 權杖**。
- 已登入並在訂閱上具備貢獻者權限的 **Azure CLI**，用於一次性狀態
  後端的初始化設定。

<Aside type="caution">
此處使用的網域已委派給 F5 XC，因此您建立的記錄將在公共網際網路上解析。
請使用您擁有且打算管理的網域 — 計劃採用變數驅動的設計，正是為了讓您能夠指定
自己的網域。
</Aside>

從[第一階段 — 建置](/dns/zh-tw/demo/phase-1-build/)開始。
