يستعرض هذا الدليل **تمرين DNS متكامل** على F5 Distributed Cloud، مدعومًا بـ Terraform.
وهو مُهيكَل على شكل أربع مراحل يمكن لمشغّل بشري أو مساعد ذكاء اصطناعي تنفيذها من البداية حتى النهاية. كل
مرحلة ذات طبيعة قابلة للتكرار: إعادة تشغيلها تُوصِل إلى الحالة ذاتها.

## مراحل التمرين

| المرحلة | الهدف |
| --- | --- |
| [المرحلة 1 — البناء](/dns/demo/phase-1-build/) | نشر منطقة DNS الأساسية باستخدام Terraform؛ وربط الحالة عن بُعد وCI |
| [المرحلة 2 — التحقق](/dns/demo/phase-2-validate/) | التأكد من أن المنطقة تُحلَّل على الإنترنت العام وأن الخطة قابلة للتكرار |
| [المرحلة 3 — التحويل عند الفشل](/dns/demo/phase-3-failover/) | إضافة موازن تحميل DNS مع تحويل عند الفشل مدعوم بفحوصات الصحة *(في انتظار وحدة DNS-LB)* |
| [المرحلة 4 — الإزالة](/dns/demo/phase-4-teardown/) | إتلاف الكائنات المُدارة بعد تأكيد صريح |

## المتطلبات الأساسية

- **Terraform** ≥ 1.5.
- موفر **`f5-sales-demo/xcsh`** ≥ 3.61.15 (الإصدار الأول الذي يتضمن موارد DNS)،
  يُحلَّل من سجل Terraform — أو بناء محلي عبر `dev_overrides`.
- **رمز API لـ F5 XC** مع صلاحية الوصول إلى مساحة الاسم `system`.
- **Azure CLI** مسجَّل الدخول بصلاحيات Contributor على الاشتراك، لبدء تشغيل الواجهة الخلفية للحالة لمرة واحدة.

<Aside type="caution">
النطاق المستخدم هنا مُفوَّض إلى F5 XC، لذا فإن السجلات التي تنشئها تُحلَّل على الإنترنت العام.
استخدم نطاقًا تمتلكه وتعتزم إدارته — فالخطة مدفوعة بالمتغيرات تحديدًا لتتمكن من استهداف
نطاقك الخاص.
</Aside>
