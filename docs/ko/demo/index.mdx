이 가이드는 Terraform으로 구동되는 F5 Distributed Cloud의 **완전한 DNS 실습**을 안내합니다.
사람 운영자 또는 AI 어시스턴트가 처음부터 끝까지 실행할 수 있는 4단계로 구성되어 있습니다. 각
단계는 멱등성을 가집니다. 즉, 다시 실행하더라도 동일한 상태로 수렴됩니다.

## 실습 단계

| 단계 | 목표 |
| --- | --- |
| [1단계 — 빌드](/dns/demo/phase-1-build/) | Terraform으로 기본 DNS 영역 배포, 원격 상태 및 CI 연결 |
| [2단계 — 검증](/dns/demo/phase-2-validate/) | 공용 인터넷에서 영역이 정상적으로 확인되고 플랜이 멱등성을 가지는지 확인 |
| [3단계 — 장애 조치](/dns/demo/phase-3-failover/) | 상태 확인 기반 장애 조치를 갖춘 DNS 부하 분산 장치 추가 *(DNS-LB 모듈 보류 중)* |
| [4단계 — 정리](/dns/demo/phase-4-teardown/) | 명시적 확인 후 관리되는 객체 삭제 |

## 사전 요구 사항

- **Terraform** ≥ 1.5.
- **`f5-sales-demo/xcsh`** 프로바이더 ≥ 3.62.0 (시스템 전용 네임스페이스는 자동으로 기본값 설정),
  Terraform 레지스트리에서 확인하거나 `dev_overrides`를 통한 로컬 빌드로 사용 가능.
- `system` 네임스페이스에 접근 권한이 있는 **F5 XC API 토큰**.
- 일회성 상태 백엔드 부트스트랩을 위해 구독에서 Contributor 권한으로 로그인된 **Azure CLI**.

<Aside type="caution">
여기서 사용하는 도메인은 F5 XC에 위임되어 있으므로, 생성한 레코드는 공용 인터넷에서 확인됩니다.
본인이 소유하고 관리하려는 도메인을 사용하십시오 — 플랜은 본인의 도메인을 대상으로 설정할 수 있도록 변수 기반으로 설계되어 있습니다.
</Aside>
