यह मार्गदर्शिका F5 Distributed Cloud पर **एक संपूर्ण DNS अभ्यास** के माध्यम से चलती है, जो Terraform द्वारा संचालित है।
इसे चार चरणों के रूप में संरचित किया गया है जिसे एक मानव ऑपरेटर या AI सहायक शुरू से अंत तक चला सकता है। प्रत्येक
चरण idempotent है: इसे पुनः चलाने पर यह उसी स्थिति में पहुँचता है।

## अभ्यास के चरण

| चरण | लक्ष्य |
| --- | --- |
| [चरण 1 — निर्माण](/dns/demo/phase-1-build/) | Terraform से प्राथमिक DNS ज़ोन तैनात करें; रिमोट स्टेट और CI को जोड़ें |
| [चरण 2 — सत्यापन](/dns/demo/phase-2-validate/) | पुष्टि करें कि ज़ोन सार्वजनिक इंटरनेट पर रिज़ॉल्व होता है और प्लान idempotent है |
| [चरण 3 — फेलओवर](/dns/demo/phase-3-failover/) | स्वास्थ्य-जाँच किए गए फेलओवर के साथ DNS लोड बैलेंसर जोड़ें *(DNS-LB मॉड्यूल लंबित)* |
| [चरण 4 — समाप्ति](/dns/demo/phase-4-teardown/) | स्पष्ट पुष्टि के बाद प्रबंधित ऑब्जेक्ट नष्ट करें |

## पूर्वापेक्षाएँ

- **Terraform** ≥ 1.5।
- **`f5-sales-demo/xcsh`** प्रोवाइडर ≥ 3.62.0 (सिस्टम-केवल नेमस्पेस स्वचालित रूप से डिफ़ॉल्ट होते हैं),
  Terraform रजिस्ट्री से रिज़ॉल्व किया गया — या `dev_overrides` के माध्यम से स्थानीय बिल्ड।
- **F5 XC API टोकन** जिसमें `system` नेमस्पेस तक पहुँच हो।
- **Azure CLI**, सदस्यता पर Contributor के रूप में साइन इन, एकमुश्त स्टेट बैकएंड बूटस्ट्रैप के लिए।

<Aside type="caution">
यहाँ उपयोग किया गया डोमेन F5 XC को सौंपा गया है, इसलिए आपके द्वारा बनाए गए रिकॉर्ड सार्वजनिक इंटरनेट पर रिज़ॉल्व होते हैं।
ऐसे डोमेन का उपयोग करें जो आपका स्वयं का हो और जिसे आप प्रबंधित करना चाहते हों — प्लान वेरिएबल-संचालित है ताकि आप इसे
अपने डोमेन पर लक्षित कर सकें।
</Aside>
