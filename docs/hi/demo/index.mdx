यह मार्गदर्शिका F5 Distributed Cloud पर Terraform द्वारा संचालित एक **संपूर्ण DNS अभ्यास** से गुज़रती है।
इसे चार चरणों में संरचित किया गया है जिन्हें कोई मानव ऑपरेटर या AI सहायक शुरू से अंत तक चला सकता है। प्रत्येक
चरण idempotent है: इसे पुनः चलाने पर वही स्थिति प्राप्त होती है।

## अभ्यास चरण

| चरण | लक्ष्य |
| --- | --- |
| [चरण 1 — निर्माण](/dns/demo/phase-1-build/) | Terraform के साथ प्राथमिक DNS ज़ोन तैनात करें; रिमोट स्टेट और CI को जोड़ें |
| [चरण 2 — सत्यापन](/dns/demo/phase-2-validate/) | पुष्टि करें कि ज़ोन सार्वजनिक इंटरनेट पर रिज़ॉल्व होता है और प्लान idempotent है |
| [चरण 3 — फेलओवर](/dns/demo/phase-3-failover/) | स्वास्थ्य-जाँचित फेलओवर के साथ DNS लोड बैलेंसर जोड़ें *(DNS-LB मॉड्यूल लंबित है)* |
| [चरण 4 — टियरडाउन](/dns/demo/phase-4-teardown/) | स्पष्ट पुष्टि के बाद प्रबंधित ऑब्जेक्ट हटाएं |

## पूर्वापेक्षाएं

- **Terraform** ≥ 1.5.
- **`f5-sales-demo/xcsh`** प्रोवाइडर ≥ 3.61.15 (DNS संसाधनों के साथ पहली रिलीज़),
  Terraform रजिस्ट्री से रिज़ॉल्व — या `dev_overrides` के माध्यम से लोकल बिल्ड।
- **F5 XC API टोकन** जिसमें `system` नेमस्पेस तक पहुंच हो।
- **Azure CLI**, सब्सक्रिप्शन पर Contributor के साथ साइन इन, एक-बार के स्टेट
  बैकएंड बूटस्ट्रैप के लिए।

<Aside type="caution">
यहाँ उपयोग किया गया डोमेन F5 XC को डेलीगेट किया गया है, इसलिए आपके द्वारा बनाए गए रिकॉर्ड सार्वजनिक इंटरनेट पर रिज़ॉल्व होते हैं।
ऐसे डोमेन का उपयोग करें जो आपके स्वामित्व में हो और जिसे आप प्रबंधित करना चाहते हों — प्लान variable-driven है ठीक इसीलिए ताकि आप
अपने स्वयं के डोमेन को लक्षित कर सकें।
</Aside>
